# ✨ El Reino Estelar de Lily ✨

Juego de plataformas cósmico 2D en HTML5 Canvas con banda sonora sintetizada mediante Web Audio API, animaciones por hojas de sprites y soporte completo para teclado y pantallas táctiles.

🎮 **Jugar en línea:** [https://dreamare.github.io/reino-estelar-lily/](https://dreamare.github.io/reino-estelar-lily/)

---

## 🌟 Características
- **Personaje:** Lily, con diadema de orejas de gato, gafas redondas, buso rosa y animaciones completas (carrera, saltos, puñetazos de cómic y estados de reposo con micro-gestos y respiración orgánica).
- **Mundos Galácticos:**
  - 🌙 *Mundo 1-1:* Noche Estelar (Polvo de hadas y cofres sorpresa)
  - 🌅 *Mundo 1-2:* Atardecer Cósmico (Lluvia estelar y plataformas con propulsores de fuego)
  - ☀️ *Mundo 1-3:* Día de Cristal (¡Rescate del gatito protector Mishi!)
  - 🐙 *Mundo 1-4:* Abismo Tenebroso (Batalla contra el Rey Kraken Marciano)
  - 🏙️ *Mundo 2-1:* Tierra Devastada (Rescate de los humanos enmascarados y escaleras)
  - 🌇 *Mundo 2-2:* Atardecer Carmesí (Supervivencia extrema y hombres zombie)
- **Controles Universales:**
  - ⬅️➡️ / `A` `D`: Caminar
  - ⬆️ / `W` / `Espacio`: Salto y Doble Salto
  - 👊 (`C` / `F` / `V`): Golpear con el Puñito
  - 🫧 (`Z` / `X` / `Shift`): Lanzar Burbujas de Corazón
  - 📱 Controles táctiles integrados en pantalla para dispositivos móviles
