✦ Guía y Créditos del Reino Estelar ✦

  • 🎮 Controles: Usa ⬅️➡️ / A / D para caminar, ⬆️ / W / Espacio para salto y doble salto, 👊 (C / F / V) para golpear y 🫧 (Z / X / Shift) para burbujas de corazón.
  • 🧰 Cofres Sorpresa: Acércate o salta encima para abrirlos y descubrir poderes y dulces. ¡50 estrellitas = 1 vida extra!
  • 🐱 Gatito Guardián (Nivel 3): En el Mundo 1-3 encontrarás a tu gatito compañero Mishi que bloquea proyectiles y dispara estrellitas.
  • 🚀 Cohete Propulsor (5s de Vuelo): Encuentra el Cohete dentro de los cofres para volar libremente manteniendo Saltar.
  • 🐙👑 Mundo 1-4 (Rey Kraken Marciano): Derrótalo saltándole encima, con el poder del Puñito 👊 o con Burbujas de Corazón 🫧.
  • 🏚️🌇 Mundos 2-1 y 2-2: Escala ruinas, rescata a los humanos enmascarados 🎭 y sobrevive al Atardecer Carmesí.
  • ✨ Créditos: El Reino Estelar de Lily — Arte conceptual, hojas de sprites animados de 12 cuadros, música sintetizada Web Audio API y motor 2D HTML5 Canvas.
